AIPrivateSearch Installation
=============================

To install:
1. Drag AIPrivateSearch.app to the Applications folder
2. Eject this disk image
3. Open Terminal and run:
   xattr -cr /Applications/AIPrivateSearch.app
4. Double-click AIPrivateSearch.app in Applications

IMPORTANT: Step 3 removes macOS quarantine that blocks downloaded apps.
Without this step, the app will not launch.

Note: This DMG includes pre-downloaded Node.js and Ollama.
The installer will use these bundled versions for faster installation.
